# 模块 M9：运动规划（教材 Ch10）★ 课程第 4 门课前半

> 本模块全部算法**必须自己写**（官方库 core.py 没有规划函数，课程作业也要求从零实现）。做完本模块你就拥有了"机械臂避障"这一完整技能块。

## 目标

1. 实现 2D 栅格 A*，理解启发式与最优性
2. 自写碰撞检测（球/胶囊），这是规划正确性的地基
3. 实现 6 自由度 UR5 的关节空间 RRT，在 MuJoCo 中执行验证
4. 理解 PRM（多查询）与势场法的适用场景与局限

## 理论（B 站 BV1KV411Z7sC 第 10 章视频 + 教材 Ch10）

- C-space 障碍：把工作空间障碍映射到 C-space，机械臂"缩成点"
- A*：评价函数 $f(n) = g(n) + h(n)$，$h$ 可采纳（admissible，不高估）时保证最优
- RRT：随机采样 + 最近邻 + 步长扩展，概率完备性
- PRM：路图（roadmap）构建一次，多查询复用
- 势场法：吸引势 $U_{att} = \tfrac{1}{2} k\, d^2(q, q_{goal})$ + 排斥势，存在局部极小问题

## 任务（自己实现）

### 任务 A：2D 栅格 A*

1. 自建迷宫（numpy 数组，随机障碍 ~30%），实现 A*（用 `heapq`），4 邻域或 8 邻域
2. 对照实验：BFS（队列）与 Dijkstra（$h = 0$ 的 A*）跑同一迷宫，比较路径长度与访问节点数
3. 验证最优性：A* 路径长度 = Dijkstra 最短路径长度

### 任务 B：碰撞检测（地基）

1. 自写 2D 线段-线段最短距离：先手算 3 组案例（相交/相切/相离）做单测
2. 扩展到 3D 胶囊-胶囊距离（胶囊 = 线段 + 半径 r）
3. 用 MuJoCo 场景中 UR5 + 障碍物的几何数据做真实验证

### 任务 C：UR5 关节空间 RRT（核心）

1. 加载 MuJoCo UR5 模型（mujoco_menagerie 的 universal_robots_ur5e 或 MuJoCo 自带场景），场景中放 2~3 个障碍物（箱子/球）
2. 关节空间 RRT：随机采样 6 维关节角 → 最近邻 → 直线插值 + 逐点碰撞检测（任务 B 的胶囊检测，几何位姿读 MuJoCo data）→ 树扩展
3. 规划从起点到目标（自选一组无碰撞起终点）
4. **执行验证**：把规划轨迹在 MuJoCo 中播放，确认无碰撞
5. 可选：PRM 版（同一场景多查询对比）；2D 势场法小车演示（观察局部极小）

## 验收标准

- [ ] A* 结果与 Dijkstra 最短路径一致（最优性验证）
- [ ] 碰撞检测单测全过（相交/相切/相离误差 < 1e-6）
- [ ] RRT 规划在 MuJoCo 中无碰撞执行成功 ≥ 10 次 / 10 次（随机换起终点）
- [ ] NOTES.md：解释 RRT 为什么"概率完备但非最优"、PRM 为什么适合多查询、势场法为什么会卡局部极小

## 卡住指南

1. 碰撞检测算不对 → 先做 2D 线段距离单测（手算案例），过了再上 3D 胶囊
2. RRT 永远找不到路径 → 检查：(a) 起终点本身是否无碰撞 (b) 步长是否太大跳过窄通道（调到关节角 0.05~0.1 rad）(c) 采样是否覆盖全关节范围
3. MuJoCo 执行时穿透 → 碰撞检测胶囊半径比实际几何放大 1.2 倍做保守处理
4. 卡超 2 小时 → 找 Claude Code 要提示
