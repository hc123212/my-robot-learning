# 模块 M6：闭链运动学（教材 Ch7，轻量模块 1~2 天）

> 闭链是并联机器人、四连杆、Stewart 平台的理论基础。本模块只求建立直觉，不深究并联机构设计。

## 目标

1. 理解"闭链 = 开链 + 闭环约束方程"
2. 在 MuJoCo 里让一个四连杆转起来（MuJoCo 默认不支持运动学闭环，这正是练习点）
3. 能写出四连杆的闭环约束方程并用仿真数据验证

## 理论（B 站 BV1KV411Z7sC 第 7 章视频 + 教材 Ch7）

- 四连杆闭环矢量环方程：

$$\vec{l}_1 + \vec{l}_2 - \vec{l}_3 - \vec{l}_0 = 0$$

标量形式为 2 个方程（x、y 分量），4 个角度中只有 1 个独立 → DOF = 1

- Grashof 条件（曲柄能整周转）：$l_{min} + l_{max} \le l_{other1} + l_{other2}$
- MuJoCo 处理闭环的两种方式：
  1. `equality` constraint（welding）：把末端"焊"回基座
  2. 软约束：小质量弹簧连接

## 任务（自己实现）

1. **四连杆 XML**：4 根杆（长度满足 Grashof 条件），3 个旋转关节 + 1 个 `equality` 约束闭环。参考 MuJoCo 文档 equality 一节
2. **驱动曲柄**：给曲柄关节加 `motor`，观察整周运转，输出从动件角度曲线
3. **开链对照**：删掉闭环约束（同一个模型变成开链），观察行为差异——理解约束的物理作用
4. **约束方程验证**：写出你的四连杆矢量环方程，代入杆长；仿真中任取 3 个角度，用方程解出第 4 个，与仿真读数对比
5. **书面回答**（NOTES.md）：Grashof 条件是什么？你的杆长为何能整周转？

## 验收标准

- [ ] MuJoCo 四连杆整周平稳运转（无爆炸、无穿透）
- [ ] 闭环约束方程代入仿真数据残差 < 1e-6
- [ ] NOTES.md 写清 Grashof 条件与闭链 DOF 计算

## 卡住指南

1. equality constraint 报错/爆炸 → 先不加电机，`mj_step` 单步看初始装配是否冲突；关节初始角度必须精确满足闭环几何
2. 整周转不了 → 检查 Grashof 条件：$l_{min} + l_{max} \le l_2 + l_3$
3. 卡超 2 小时 → 找 Claude Code 要提示
