# 阶段 3：逆向运动学 IK（第 4 周）

## 目标
- 理解数值 IK（牛顿法 / 阻尼最小二乘）原理
- 理解 IK 多解、奇异、不可达的处理

## 理论（Modern Robotics 第 6 章）
从 FK 误差迭代求关节角：q_new = q + J⁺·Δx；**阻尼最小二乘** J⁺ = Jᵀ(JJᵀ + λ²I)⁻¹ 的来历；雅可比伪逆

## 实验（自己做）
1. 复用阶段 2 的 2 连杆臂模型和 FK 函数
2. 实现阻尼最小二乘 IK：给目标点，迭代至 ‖Δx‖ < 1e-4
3. 用 MuJoCo 可视化：IK 求解出的关节角直接设进仿真，看到末端到达目标点
4. 测试三种情况：可达点（收敛）/ 边界点（慢速收敛）/ 不可达点（报告不可达不崩溃）
5. 对比不同阻尼系数 λ 的收敛速度（λ=0 与 λ=0.1）

## 验收
- [ ] 可达点误差 < 1e-4
- [ ] 不可达时能判断并输出提示，而不是振荡/发散
- [ ] NOTES.md：解释为什么 λ=0 时在奇异位形附近会"关节速度爆炸"
