# 模块 M5：逆向运动学 IK（教材 Ch6）

## 目标

- 理解数值 IK（牛顿法 / 阻尼最小二乘）原理
- 理解 IK 多解、奇异、不可达的处理

## 理论（B 站 BV1KV411Z7sC 第 6 章视频 + 教材 Ch6）

- 从 FK 误差迭代求关节角：$q_{new} = q + J^{+}\Delta x$
- **阻尼最小二乘**：$J^{+} = J^{\mathsf{T}}(JJ^{\mathsf{T}} + \lambda^2 I)^{-1}$ 的来历；雅可比伪逆
- 局部极小、奇异位形附近行为

## 实验（自己做）

1. 复用 M3 的 2 连杆臂模型和 FK 函数
2. 实现阻尼最小二乘 IK：给目标点，迭代至 $\|\Delta x\| < 1\mathrm{e}{-4}$
3. 用 MuJoCo 可视化：IK 求解出的关节角直接设进仿真，看到末端到达目标点
4. 测试三种情况：可达点（收敛）/ 边界点（慢速收敛）/ 不可达点（报告不可达不崩溃）
5. 对比不同阻尼系数 $\lambda$ 的收敛速度（$\lambda = 0$ 与 $\lambda = 0.1$）
6. **对照库**（新增）：与 `modern_robotics_lib` 的 `IKinSpace` 在相同输入下对比迭代结果

## 验收

- [ ] 可达点误差 < 1e-4
- [ ] 不可达时能判断并输出提示，而不是振荡/发散
- [ ] 与库 `IKinSpace` 结果一致（同初值下收敛到同一位形）
- [ ] NOTES.md：解释为什么 $\lambda = 0$ 时在奇异位形附近会"关节速度爆炸"、为什么 $\lambda$ 越大收敛越慢但越稳

## 卡住

迭代发散 → 检查雅可比求法（用 M4 的数值差分验证）；$\lambda$ 从 0.1 起调，别一上来用 0。
