# 阶段 4：速度运动学与雅可比（第 5 周）

## 目标
- 理解几何雅可比 J 的定义（q̇ → 末端速度的映射）
- 理解奇异位形（rank(J) 下降）与可操作性
- 掌握力域映射 τ = JᵀF（静力传递）

## 理论（Modern Robotics 第 5 章）
雅可比定义与求法、数值雅可比（有限差分）、雅可比的奇异、力域映射与虚功原理

## 实验（自己做）
1. 数值雅可比：对 2 连杆 FK，用有限差分 `J_ij = Δx_i / Δq_j`（扰动 1e-6）
2. 对多组关节角计算 `rank(J)`、`det(J·Jᵀ)`（可操作性度量）
3. **奇异演示**：让臂走到"完全伸直"位形，观察可操作性 → 0
4. **力域验证**：在仿真中对末端施加已知力 F，读关节力矩，验证 τ = JᵀF（与 MuJoCo 的 `data.qfrc_actuator` 对比）
5. 奇异附近 IK 收敛变慢的现象，与你阶段 3 的观察对照
