# 模块 M4：速度运动学与雅可比（教材 Ch5）

## 目标

- 理解雅可比 $J$ 的定义（$\dot{q} \to$ 末端速度的映射）
- 理解奇异位形（$\mathrm{rank}(J)$ 下降）与可操作性
- 掌握力域映射 $\tau = J^{\mathsf{T}}F$（静力传递）

## 理论（B 站 BV1KV411Z7sC 第 5 章视频 + 教材 Ch5）

- 雅可比定义与求法（空间/本体雅可比）、数值雅可比（有限差分）、雅可比的奇异、力域映射与虚功原理

## 实验（自己做）

1. 数值雅可比：对 2 连杆 FK，用有限差分 $J_{ij} = \dfrac{\Delta x_i}{\Delta q_j}$（扰动 1e-6）
2. 对多组关节角计算 $\mathrm{rank}(J)$、$\det(JJ^{\mathsf{T}})$（可操作性度量）
3. **奇异演示**：让臂走到"完全伸直"位形，观察可操作性 → 0
4. **力域验证**：在仿真中对末端施加已知力 F，读关节力矩，验证 $\tau = J^{\mathsf{T}}F$（与 MuJoCo 的 `data.qfrc_actuator` 对比）
5. 奇异附近 IK 收敛变慢的现象，与你 M5 的观察对照
6. **对照库**（新增）：手写 `JacobianSpace` / `JacobianBody`，与 `modern_robotics_lib` 同函数对照
