# 阶段 5：动力学 —— 拉格朗日方程（第 6-7 周）★ 分水岭

> 这是整个计划最难的一周半，拆两周完成。动力学是后续所有控制（CTC、阻抗、RL）的模型基础。

## 目标
- 理解动力学方程 `M(q)·q̈ + C(q,q̇)·q̇ + G(q) = τ` 三项的物理意义
- 会用手推 2 连杆的拉格朗日方程（至少推一遍，这是核心练习）
- 会用 MuJoCo 逆动力学接口（`mj_inverse`）获得"真实"动力学数据

## 理论（Modern Robotics 第 8 章；Craig 第 6 章）
拉格朗日函数 L = T - V、广义力、质量矩阵 M 与惯性项、科氏力/离心力 C、重力项 G、牛顿-欧拉递推（对比理解即可）

## 实验（自己做）
1. **手推** 2 连杆平面臂的动力学方程（用拉格朗日法，写成 M/C/G 三项显式表达式）
2. MuJoCo 加载 2 连杆臂，用 `mujoco.mj_inverse` 接口：给定 q、q̇、q̈ 的运动，返回所需力矩 τ_inv
3. **对比验证**：把你的 M、C、G 解析表达式算出的 τ 与 mj_inverse 对比，误差 < 1e-2
4. **计算力矩控制 CTC**：τ = M·(q̈_des + Kp·e + Kd·ė) + C + G，跟踪一条正弦轨迹
5. 画图对比：纯 PD 跟踪误差 vs CTC 跟踪误差（CTC 应小 1-2 个数量级）
