## 理论背景（教材内容，直接给你）

弹簧-阻尼系统（单自由度）标准方程：

```
m·ẍ + c·ẋ + k·x = 0
```

改写成标准形式：`ẍ + 2ζ·ωₙ·ẋ + ωₙ²·x = 0`，其中：

- `ωₙ = √(k/m)` —— **固有频率**（无阻尼时的振荡频率）
- `ζ = c / (2√(mk))` —— **阻尼比**，决定一切：

| ζ | 类型 | 特征根 | 响应 |
|---|---|---|---|
| ζ > 1 | 过阻尼 | 两个负实根 | 缓慢爬回零点，无振荡 |
| ζ = 1 | 临界阻尼 | 重根 | 最快无振荡回到零点 |
| 0 < ζ < 1 | 欠阻尼 | 共轭复根 | 振荡衰减，频率 ω_d = ωₙ·√(1-ζ²) |

## 任务 B：线性代数预热 —— 旋转矩阵基础（M0 新增）

### 理论背景

旋转矩阵 R ∈ SO(3)：满足 **RᵀR = I**（正交）、**det(R) = +1**。

- 矩阵乘法 = 复合变换；R 的逆 = R 的转置
- 反对称矩阵 ω̂：满足 ω̂ᵀ = -ω̂，且 ω̂·v = ω × v
- 矩阵指数：exp(A) = I + A + A²/2! + A³/3! + …

### 任务（自己实现）

1. **正交性推导**：手推证明 RᵀR = I ⟺ R 的各列是单位正交向量；由 det(RᵀR) = det(R)² 推出 det(R) = ±1
2. **numpy 造旋转矩阵**：给定转轴 ω 和转角 θ，用 Rodrigues 公式实现 R（手写，不调库）；数值验证 RᵀR = I 的误差 <1e-12、det(R) = 1
3. **反对称矩阵**：手写 ω̂ 构造函数；数值验证 ω̂·v = ω × v（与 `np.cross` 对照）
4. **矩阵指数**：把 exp(ω̂θ) 泰勒展开到前 4 项，发现 ω̂³ = -ω̂ 的循环规律，验证展开式与 Rodrigues 公式结果一致（数值对照）
