### 需要先复习的数学

- 二阶线性常系数齐次 ODE 的**特征方程解法**：$m\ddot{x} + c\dot{x} + kx = 0$，特征方程 $ms^2 + cs + k = 0$
- 根的性质（两个实根 / 重根 / 共轭复根）→ 通解形式 → 初始条件定系数

### 理论背景（教材内容，直接给你）

弹簧-阻尼系统（单自由度）标准方程：

$$m\ddot{x} + c\dot{x} + kx = 0$$

改写成标准形式：$\ddot{x} + 2\zeta\omega_n \dot{x} + \omega_n^2 x = 0$，其中：

- $\omega_n = \sqrt{k/m}$ —— **固有频率**（无阻尼时的振荡频率）
- $\zeta = \dfrac{c}{2\sqrt{mk}}$ —— **阻尼比**，决定一切：

| $\zeta$ | 类型 | 特征根 | 响应 |
|---|---|---|---|
| $\zeta > 1$ | 过阻尼 | 两个负实根 | 缓慢爬回零点，无振荡 |
| $\zeta = 1$ | 临界阻尼 | 重根 | 最快无振荡回到零点 |
| $0 < \zeta < 1$ | 欠阻尼 | 共轭复根 | 振荡衰减，频率 $\omega_d = \omega_n\sqrt{1-\zeta^2}$ |

### 任务（自己实现）

2. **数值解**：把二阶方程改写成一阶方程组（状态变量 $x_1 = x,\; x_2 = \dot{x}$），用 `scipy.integrate.solve_ivp` 在 $t \in [0, 20]$ 上数值求解同一问题

4. **可视化**：一张图上画出 $\zeta = 0.2 / 1.0 / 2.0$ 三条响应曲线（不同颜色），加图例、轴标签

### 提示（不是答案）

## 任务 B：线性代数预热 —— 旋转矩阵基础（为 M2 刚体运动预热）

> 先看 3Blue1Brown《线性代数的本质》第 1~8 集（B 站）。

### 理论背景

旋转矩阵 $R \in SO(3)$：满足 **$R^{\mathsf{T}}R = I$**（正交）、**$\det(R) = +1$**。

- 矩阵乘法 = 复合变换；$R$ 的逆 = $R$ 的转置
- 反对称矩阵 $\hat{\omega}$：满足 $\hat{\omega}^{\mathsf{T}} = -\hat{\omega}$，且 $\hat{\omega}v = \omega \times v$
- 矩阵指数：$\exp(A) = I + A + \dfrac{A^2}{2!} + \dfrac{A^3}{3!} + \cdots$

### 任务（自己实现）

1. **正交性推导**：手推证明 $R^{\mathsf{T}}R = I \iff R$ 的各列是单位正交向量；由 $\det(R^{\mathsf{T}}R) = \det(R)^2$ 推出 $\det(R) = \pm 1$
2. **numpy 造旋转矩阵**：给定转轴 $\omega$ 和转角 $\theta$，用 Rodrigues 公式实现 R（手写，不调库）；数值验证 $R^{\mathsf{T}}R = I$ 的误差 < 1e-12、$\det(R) = 1$
3. **反对称矩阵**：手写 $\hat{\omega}$ 构造函数；数值验证 $\hat{\omega}v = \omega \times v$（与 `np.cross` 对照）
4. **矩阵指数**：把 $\exp(\hat{\omega}\theta)$ 泰勒展开到前 4 项，发现 $\hat{\omega}^3 = -\hat{\omega}$ 的循环规律，验证展开式与 Rodrigues 公式结果一致（数值对照）
5. **书面回答**（写进 NOTES.md）：
   - 为什么旋转矩阵的逆就是转置？（从正交性/几何角度）
   - $\det(R) = -1$ 的变换是什么？（提示：镜像反射）
   - 特征值 1 的特征向量对应什么？（提示：旋转轴）
