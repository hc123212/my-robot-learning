# 模块 M13：Capstone —— 移动机械臂综合项目（课程第 6 门课）

> 本模块无新理论，是 M1~M12 全部技能的**滚动复用**。
> 规则：**必须使用你自己在前序模块写的代码**（FK / IK / RRT / 控制 / 底盘控制），禁止临时换成库函数。写完在 NOTES.md 里列清每个环节调用了哪个模块的哪个函数。

## 任务场景

移动底盘 + 机械臂（建议 MuJoCo 自带移动机械臂模型，或 UR5e 装在差速底盘上），场景设：1 个桌面/货架 + 1 个障碍物 + 1 个目标放置区。

**完整流程**：

1. **底盘导航**：从起点开到工作台前停靠点（复用 M12 的反馈控制）
2. **抓取规划**：物体位姿已知（跳过视觉），UR5 关节空间 RRT 规划到预抓取位（复用 M9 的 RRT + 碰撞检测）
3. **抓取**：闭合夹爪（复用 M11 的参数经验），判定抓稳后再动作
4. **放置规划**：RRT 规划到放置位（复用 M9）
5. **放置与退回**：张开夹爪，底盘退回起点

## 任务（自己实现）

1. **场景搭建**：自建 MuJoCo 场景（参考 `mujoco_tutorial/02_MJCF建模语言.md` 与 balance_sim 的建模经验）
2. **分阶段联调**：先底盘导航单独跑通 → 再手臂规划单独跑通 → 最后整流程串联
3. **完整流程自动化**：写成主脚本，一键运行整个任务
4. **重复性测试**：物体 3 个不同位置 × 底盘 2 个起点 = 6 组，每组跑 2 次，统计成功率
5. **误差链分析**（写进 NOTES.md）：定位误差 → 规划误差 → 控制跟踪误差 → 抓取误差，各环节误差来源与量级（用仿真实测数据说话）

## 验收标准

- [ ] 完整任务无碰撞成功 ≥ 5 次 / 10 次
- [ ] 所有代码为自写模块的复用（NOTES.md 列清调用清单）
- [ ] 误差链分析有实测数据支撑（每环节记录实际误差）

## 卡住指南

1. 整流程太复杂 → 严格分阶段：每天只联调一环，先让"导航到停靠点"本身稳定
2. 抓取总掉 → 回 M11 检查夹持力与摩擦参数；夹爪闭合后停留 0.5 s 再抬升
3. 碰撞检测误报 → 检查胶囊半径是否过保守，或在靠近目标位时切换精细插值
4. 卡超 2 小时 → 找 Claude Code 要提示
