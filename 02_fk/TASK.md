# 阶段 2：正向运动学 DH-FK（第 3 周）

## 目标
- 理解 DH 参数法（4 个参数：a, α, d, θ）与坐标系建立规则
- 会从 DH 参数表推导末端位姿（变换链乘积）

## 理论（Modern Robotics 第 4 章；Craig 第 3 章）
DH 约定（标准 DH 或改进 DH 选一种，写清楚你用的哪种）、连杆变换矩阵 Aᵢ、正向运动学 T = A₁·A₂·…·Aₙ

## 实验（自己做）
1. 自己写一个 2 连杆平面臂的 MuJoCo XML（两个旋转关节，臂长自己定）
2. 手写 DH → FK 函数：输入 2 个关节角，输出末端位置（numpy 实现，不允许用现成库）
3. MuJoCo 仿真中随机取 10 组关节角，读仿真末端位置，与你的 FK 函数对比
4. 画误差分布（应 < 1e-6）

## 验收
- [ ] 10 组随机关节角误差全部 < 1e-6
- [ ] 换一组不同的臂长参数，重算仍一致（参数化，不是写死）
