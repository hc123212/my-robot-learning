## 10.1 官方教程与 notebook（第一优先级）

MuJoCo 官方仓库自带 Jupyter notebook 教程（Colab 可直接跑），**在你完成第 1~4 阶段后逐本过一遍**，验证你对 API 的理解：

| notebook | 内容 | 建议时机 |
|---|---|---|
| `tutorial.ipynb` | MuJoCo 入门总纲 | 读完本指导书第 1~3 章后 |
| `mjspec.ipynb` | 程序化建模（MjSpec，代码建模型不写 XML） | 第 4 阶段后（进阶） |
| `rollout.ipynb` | 多线程批量仿真（一次跑几千条轨迹） | 第 7 阶段后（批处理实验） |
| `LQR.ipynb` | 线性二次型控制器让人形单腿平衡 | 第 6 阶段后（进阶） |
| `least_squares.ipynb` | 非线性最小二乘求解器 | 系统辨识相关 |
| `mjx/tutorial.ipynb` | MJX（JAX 版 MuJoCo）入门 | 想上 GPU RL 时 |

位置：<https://github.com/google-deepmind/mujoco> 的 `tutorials/` 目录，README 里有 Colab 链接。

## 10.2 MuJoCo Menagerie：官方机器人模型库（强烈推荐）

<https://github.com/google-deepmind/mujoco_menagerie>

DeepMind 维护的高质量机器人模型集合，**"开箱即用"**（2026-07 仍在活跃维护）。模型覆盖：

- **人形**：Unitree H1 / G1、Apptronik Apollo、Fourier N1、Berkeley Humanoid、Robotis OP3
- **四足**：Unitree A1 / Go1 / Go2、ANYmal B/C、Spot（12~19 自由度）
- **双足**：Agility Cassie
- **机械臂**：Franka Panda（7 关节，教学最爱）、UR5e / UR10e、KUKA iiwa14、Kinova Gen3、xArm7
- **灵巧手**：Allegro Hand、Shadow Hand、Leap Hand、Robotiq 2F-85
- **移动操作**：ALOHA 2（双臂）、Stretch 2/3、TidyBot
- 每个模型都带 `assets/`（网格）、`scene.xml`（可直接 Simulate 打开）、README（说明建模方法、质量等级）

**两种使用方式**：

```bash
# 方式 1：直接 clone
git clone https://github.com/google-deepmind/mujoco_menagerie.git
python -m mujoco.viewer --mjcf=mujoco_menagerie/franka_emika_panda/scene.xml

# 方式 2：robot_descriptions 包（自动下载，路径即用）
pip install robot_descriptions
python -c "import mujoco, robot_descriptions as rd; m = mujoco.MjModel.from_xml_path(rd.FRANKA_EMIKA_PANDA_XML); print(m.njnt)"
```

**学习建议**：完成阶段 2~4 后，用 Menagerie 的 Panda 机械臂重做一遍 FK/雅可比实验——真实模型的验证比自建 2 连杆更有成就感。阶段 6 的 PD 控制学完，可以试试让 Panda 保持姿态。模型自带 quality 分级（A+ = 系统辨识过），读每个模型的 README 也是一种学习。

## 10.3 dm_control：DeepMind 控制套件（RL 标准环境）

<https://github.com/google-deepmind/dm_control>

DeepMind 官方的 RL 环境套件（Cartpole、Cheetah、Walker、Humanoid 等，用 MuJoCo 物理）。**特点**：环境定义完全走 MJCF + task 描述文件，是"自己搭 RL 实验台"的极佳范本。

```bash
pip install dm_control
python -c "from dm_control import suite; env = suite.load('cartpole', 'balance'); print(env.observation_spec())"
```

与 gymnasium 的对比：接口不同（dm_env 规范），但环境种类更丰富、可视化更好。建议在 gymnasium 之后接触，作为对照学习。

## 10.4 mujoco_playground：GPU 加速 RL（进阶）

<https://github.com/google-deepmind/mujoco_playground>

DeepMind 官方，基于 **MJX**（MuJoCo 的 JAX 分支）的 GPU 并行训练环境套件：

- dm_control 经典任务的 MJX 复刻（Cartpole、Walker、Humanoid 等 25+）
- 基于 Menagerie 机器人的运动控制任务 19 个（Go1 遥控行走、Spot 起立、G1/H1 步态跟踪……），11 个带域随机化
- 需要 JAX + CUDA GPU（普通台式机也能跑小任务）

**时机**：完成第 8 阶段（CPU 上 PPO 训 Pendulum）之后。MJX 的意义：一卡能并行几千个环境，训练速度提升 1~2 个数量级——现代具身智能研究的事实标准。

## 10.5 robosuite：研究级操作仿真框架（双臂/抓取）

<https://github.com/ARISE-Initiative/robosuite>

斯坦福等维护的操作任务框架（v1.5.2，2025-12 发布，仍在活跃开发）：

- 双臂操作、抓取、放置等标准化任务
- 多种机械臂（Panda、UR5e、iiwa 等）+ 复合控制器（关节/操作空间/整机）
- 配套 **robomimic** 做演示采集与模仿学习

**时机**：想走"操作/模仿学习"方向时。它与 Menagerie 的区别：Menagerie 给"模型"，robosuite 给"任务+框架"。

## 10.7 选型决策表（什么时候用什么）

| 你的需求 | 选它 |
|---|---|
| 手写 XML 建模 + 直接控制（学习计划主线） | 本指导书 + 官方 docs |
| 要一个真实机器人的现成模型 | **Menagerie**（+ robot_descriptions） |
| RL 环境（标准接口、快速迭代） | **gymnasium v5**（第 9 章） |
| 更丰富的连续控制任务环境 | dm_control |
| GPU 大规模并行训练 / 可微物理 | MJX / mujoco_playground |
| 双臂操作、抓取、模仿学习 | robosuite + robomimic |
| 人形全身控制 benchmark | HumanoidBench |
| 系统辨识 / 模型编辑 | 官方 sysid 工具、mjspec notebook |

## 10.8 进阶路线图（完成学习计划后）

```
第 8 阶段完成（PPO 跑通 Pendulum）
  │
  ├─ 路线 A（运动控制）: Menagerie 四足/人形 → mujoco_playground → MJX 大规模训练
  ├─ 路线 B（操作）: Panda 模型 + robosuite 任务 → robomimic 模仿学习
  └─ 路线 C（具身智能落地）: LeRobot → RDK 板子部署（对应你的 rdk-embodied-lerobot 技能）
```

三路线共用你的 MuJoCo 技能：XML 建模、动力学接口、控制链路、gym 封装——第 10 章的每个项目都建立在这些能力之上。
