## 5.1 本章地位：MuJoCo 是你的"参考答案"

你的学习计划有一个贯穿始终的验证铁律：

> 理论公式 → 代码 → 仿真数据，三者对照；误差对不上就回头查数学。

MuJoCo 在这条链里扮演**参考答案**的角色——它不是替代你算，而是让你算完有个权威对照。所以本章的全部内容可以概括为一句话：

**学会在任何位形下，从 MuJoCo 读出你要对比的那个量（位置、姿态、速度、雅可比、力）。**

## 5.2 正运动学数据源：位置与姿态

mujoco.mj_forward(model, data)      # 先同步（改过 qpos 必做）

**阶段 1 实验对照**：你从 `data.joint("pivot").qpos` 读摆角 $\theta$ → 自己构造 $R(\theta)$ → 算摆端世界坐标 → 与 `data.site("pendulum_end").xpos` 对比。注意四元数约定：MuJoCo 用 `[w x y z]` 顺序（与 Modern Robotics 教材不同，教材常用 `[x y z w]` 或矩阵形式——转换时小心，这是经典错误）。

**阶段 2 实验对照**：你手写 DH-FK 的末端位置 vs `data.site("tip").xpos`。

## 5.3 速度：读 qvel 与空间速度

```python
data.qvel              # (nv,) 关节角速度（广义速度）
```

注意 `data.qvel` 对 free/ball 关节是**三维角速度**（不是四元数导数）——这正是 nv < nq 的原因。

**空间速度**（刚体的完整 6D 速度，阶段 4 验证用）：`mj_objectVelocity` 返回任意对象的世界系空间速度 `[线速度(3), 角速度(3)]`：

```python
vel = np.zeros(6)
mujoco.mj_objectVelocity(model, data,
                         mujoco.mjtObj.mjOBJ_SITE,   # 对象类型
                         model.site("tip").id,        # 对象 id
                         vel, 0)                      # 输出 + 坐标系(0=世界)
# vel[:3] = 世界系线速度, vel[3:] = 世界系角速度（实测验证通过）
```

## 5.4 雅可比：mj_jac 家族

雅可比是阶段 4 的主角。MuJoCo 提供现成接口（**3.11 实测可用**）：

```python
# 平移雅可比 Jp(3×nv) 和旋转雅可比 Jr(3×nv)，都写到输出数组
Jp = np.zeros((3, model.nv))
Jr = np.zeros((3, model.nv))
mujoco.mj_jacSite(model, data, Jp, Jr, model.site("tip").id)
# mj_jac / mj_jacBody / mj_jacGeom 同理，只是对象类型不同

# 对 site：线速度 = Jp @ qvel，角速度 = Jr @ qvel
v_linear = Jp @ data.qvel
v_angular = Jr @ data.qvel
```

**签名速查**（4 个常用）：

| 函数 | 对象 | 签名（前 4 个参数都是输出） |
|---|---|---|
| `mj_jac` | 任意对象（mjOBJ_*） | `mj_jac(m, d, Jp, Jr, objtype, objid)` |
| `mj_jacSite` | site | `mj_jacSite(m, d, Jp, Jr, site_id)` |
| `mj_jacBody` | body | `mj_jacBody(m, d, Jp, Jr, body_id)` |
| `mj_jacGeom` | geom | `mj_jacGeom(m, d, Jp, Jr, geom_id)` |

**雅可比的语义**（和教材对应）：

- Jp 的第 i 列 = 关节 i 的转轴方向 × (末端位置 − 关节 i 位置)——教材里"对末端位置求偏导"，MuJoCo 内部就是这么算的。
- 平移/旋转分开成两个 (3, nv) 矩阵，合起来 (6, nv) 就是教材的几何雅可比。
- **行列约定**：MuJoCo 是"列雅可比"（J @ qvel = 笛卡尔速度），与 Modern Robotics 教材一致，与部分教材的"行雅可比"相反——对比公式时先确认约定。

**数值差分验证法**（阶段 4 任务书要求"自己差分 qpos 后验证"，标准做法）：

```python
def numeric_jac(model, data, site_name, eps=1e-7):
    """中心差分雅可比：末端位置对每个关节角的偏导。"""
    mujoco.mj_forward(model, data)
    p0 = data.site(site_name).xpos.copy()
    J = np.zeros((3, model.nv))
    for i in range(model.nv):
        qp = data.qpos.copy(); qp[i] += eps
        data.qpos[:] = qp; mujoco.mj_forward(model, data)
        p_plus = data.site(site_name).xpos.copy()
        qm = data.qpos.copy(); qm[i] -= 2*eps
        data.qpos[:] = qm; mujoco.mj_forward(model, data)
        p_minus = data.site(site_name).xpos.copy()
        J[:, i] = (p_plus - p_minus) / (2*eps)
    data.qpos[:] = qp_restore  # 记得恢复原 qpos（或用 try/finally）
    return J
```

（数值差分的对照物就是 `mj_jacSite` 的输出——两者应在 1e-5 量级内一致。）

## 5.5 力域验证：$\tau = J^{\mathsf{T}}F$（阶段 4 的重点实验）

教材里的对偶关系：末端施加力 F，等效关节力矩 $\tau = J^{\mathsf{T}}F$。MuJoCo 里用 **`mj_applyFT`** 施加外力并拿到等效广义力（**3.11 实测验证：输出与 $J^{\mathsf{T}}F$ 完全一致**）：

```python
F = np.array([10.0, 0, 0])                     # 世界系力（N）
tau_eq = np.zeros(model.nv)                    # 输出：等效广义力（nv 长度！）
mujoco.mj_applyFT(model, data,
                  F,                           # 力 (3,)
                  np.zeros(3),                 # 力矩 (3,)
                  data.site("tip").xpos,       # 力的作用点（世界系）
                  model.body("link2").id,      # 力所属的刚体
                  tau_eq)                      # 等效广义力输出 ← 第 7 个参数
```

**实测结果**（2 连杆臂，q=[0.3, −0.5]，末端 10N 沿 x）：`tau_eq = [-0.3874, 0.7947]`，与 `Jp.T @ F` 完全相等。

**阶段 4 任务书修正提醒**：任务书里写"与 `data.qfrc_actuator` 对比"——实测表明，**施加到 `data.xfrc_applied` 的外力并不会反映在 `qfrc_applied` 或 `qfrc_actuator` 里**（两者保持 0）。3.11 的正确做法：

1. 用 `mj_applyFT` 的 `tau_eq` 输出对比你的 $J^{\mathsf{T}}F$（推荐，最直接）；
2. 或者设 `data.xfrc_applied[body_id, :] = [F, torque]` 后仿真，观测**动力学响应**（加速度、平衡位置）间接验证。

若想验证"手写雅可比"而非"手写 $J^{\mathsf{T}}F$"，顺序可以是：手写雅可比 J 手算 → 数值差分验证 → 与 mj_jacSite 对比 → 再与 mj_applyFT 输出的 tau_eq 对比 $J^{\mathsf{T}}F$ 的一致性。**链条闭合，数学就稳了。**

## 5.6 IK 实验的 MuJoCo 配套技能（阶段 3）

阶段 3 的阻尼最小二乘 IK 完全是你自己写，MuJoCo 提供两件事：

**1. 把解算的关节角"打"进仿真看效果：**

```python
data.qpos[:] = q_ik                # q_ik 是你的 IK 解
mujoco.mj_forward(model, data)     # 同步运动学
tip = data.site("tip").xpos
error = np.linalg.norm(tip - target)   # 评估 IK 精度
```

**2. 雅可比用于迭代**：阻尼最小二乘 $\Delta q = J^{\mathsf{T}}(JJ^{\mathsf{T}} + \lambda^2 I)^{-1} \Delta x$，J 用 `mj_jacSite` 拿（先对比验证你的解析 J，再用哪个都可以）。

```python
delta_x = target - data.site("tip").xpos
Jp = np.zeros((3, model.nv))
mujoco.mj_jacSite(model, data, Jp, None, model.site("tip").id)
delta_q = Jp.T @ np.linalg.solve(Jp @ Jp.T + lam**2 * np.eye(3), delta_x)
data.qpos[:] += delta_q
mujoco.mj_forward(model, data)
# 循环直到误差 < 阈值
```

## 5.7 姿态的读取与换算（阶段 1 的细节）

```python
# 四元数 wxyz -> 旋转矩阵（手算验证时常用）
from scipy.spatial.transform import Rotation as R
quat = data.body("link2").xquat                    # [w x y z]
mat = R.from_quat([quat[1], quat[2], quat[3], quat[0]]).as_matrix()  # scipy 用 xyzw
# 对比 data.body("link2").xmat 按行 reshape 成的 3×3 矩阵
```

注意两个约定坑：
1. MuJoCo `xquat` 是 **wxyz**，scipy `from_quat` 要 **xyzw**——换序。
2. MuJoCo `xmat` 是 **9 个元素按行展开**（row-major），reshape(3,3) 直接可用。

## 5.8 本章小结：阶段 1~4 的 MuJoCo API 对照表

| 实验 | 你要写的 | MuJoCo 提供的"真值" |
|---|---|---|
| 阶段 1 单摆位姿 | $R(\theta)$、四元数、万向锁 | `data.joint("pivot").qpos`、`data.site().xpos/xquat/xmat` |
| 阶段 2 DH-FK | 手写 FK 函数 | `data.site("tip").xpos`（改 qpos → mj_forward → 读） |
| 阶段 3 IK | DLS 迭代 | `mj_jacSite` 的 J、`data.site().xpos` 反馈 |
| 阶段 4 雅可比 | 解析 J、数值差分 | `mj_jacSite`、`mj_objectVelocity`、`mj_applyFT`(tau_eq) |

**反复出现的三步模式**（务必形成肌肉记忆）：

```python
data.qpos[:] = ...            # 1. 设状态
mujoco.mj_forward(model, data)  # 2. 同步
value = data.xxx.copy()       # 3. 读真值（.copy() 保护！）
```
