## 1.1 MuJoCo 是什么

MuJoCo（Multi-Joint dynamics with Contact）是 Google DeepMind 开源的物理引擎，机器人领域的事实标准：

- **广义坐标建模**：用关节坐标（qpos/qvel）而不是笛卡尔坐标描述机器人，天然适配机器人学教材的符号体系（《Modern Robotics》的 C 空间、雅可比、拉格朗日动力学全部直接对应）。
- **接触求解**：基于凸优化的软约束求解器，接触稳定、不穿透，适合双足、抓取等任务。
- **速度极快**：单线程 C 实现，配合 MJX（JAX 分支）可在 GPU 上跑大规模并行 RL。
- **生态庞大**：DeepMind 官方模型库（Menagerie）、gymnasium、robosuite、dm_control 都基于它。

**MuJoCo 的定位**：它是**仿真内核**（物理计算），不是"建模软件"。你在文本文件里写 XML 描述机器人（MJCF 格式），MuJoCo 把它编译成模型（MjModel），然后推演物理（MjData + mj_step）。没有图形界面拖拽建模这一说——这是它和 Gazebo、Isaac Sim 最大的区别，也是它轻量的原因。

## 1.4 第一个仿真脚本：Hello MuJoCo

新建 `hello_mujoco.py`，内容如下（**实测可运行**）：

```python
"""MuJoCo 3.11 第一个脚本：加载内置模型并仿真 2 秒。"""
import mujoco
import numpy as np

# 1. 用 XML 字符串创建一个最简模型：一个在重力下自由下落的球
xml = """
<mujoco model="hello">
  <worldbody>
    <geom type="plane" size="2 2 0.1"/>          <!-- 地面 -->
    <body name="ball" pos="0 0 0.3">
      <joint name="free" type="free"/>            <!-- 6 自由度自由关节 -->
      <geom type="sphere" size="0.1" mass="1.0"/> <!-- 半径 0.1m、质量 1kg 的球 -->
    </body>
  </worldbody>
</mujoco>
"""

# 2. XML 字符串 -> MjModel（编译阶段，只做一次）
model = mujoco.MjModel.from_xml_string(xml)

# 3. MjModel -> MjData（运行状态，每步更新）
data = mujoco.MjData(model)

print(f"模型信息: {model.nq} 个广义坐标, {model.nbody} 个刚体, 时间步长 {model.opt.timestep}s")

# 4. 仿真循环：time 是仿真内部时间，单位秒
while data.time < 2.0:
    mujoco.mj_step(model, data)

# 5. 读取结果：球最终停在地面上（z = 半径 0.1）
print(f"仿真结束: t = {data.time:.2f}s")
print(f"球心位置: {data.body('ball').xpos}")   # 期望 z ≈ 0.1

# 6. 对照物理：自由落体 0.2m 用时 sqrt(2*0.2/9.81) ≈ 0.2s，此时已落地静止
```

运行：

```bash
python hello_mujoco.py
```

输出类似：

```
模型信息: 7 个广义坐标, 2 个刚体, 时间步长 0.002s
仿真结束: t = 2.00s
球心位置: [ 0.          0.        0.10019877]
```

球停在 z≈0.1 —— 物理正确（球半径 0.1，静置在平面上）。**你的第一个仿真跑通了。**

### 这段代码里的核心心智模型（全书最重要的一段）

```
MJCF(XML 文本) ──编译──▶ MjModel(静态结构) ──实例化──▶ MjData(动态状态)
                                                            │
                                                    每步调用 mj_step
                                                            │
                                                    物理状态前进一个 dt
```

- **MjModel**：机器人的"图纸"——刚体树、关节、几何体、执行器、传感器。加载后不再改动。
- **MjData**：机器人的"状态"——位置、速度、加速度、控制输入、接触力。每步仿真都在变。
- **mj_step(model, data)**：把 data 推进一步（默认 0.002 秒）。这是 MuJoCo 的灵魂函数。

## 1.5 可视化：MuJoCo Simulate 程序

MuJoCo 自带一个仿真器程序（Simulate），用来交互式地看模型、拖拽物体、调节相机。**3.11 的变化**：以前用 `python -m mujoco.simulate`，现在该模块已移除，改为：

```bash
# 方式一：命令行指定模型（3.11 推荐）
python -m mujoco.viewer --mjcf=hello_mujoco 的模型.xml

# 方式二：不指定模型，打开空窗口后把 .xml 文件拖进窗口
python -m mujoco.viewer
```

把上一节的 XML 存成 `hello.xml`，然后：

```bash
python -m mujoco.viewer --mjcf=hello.xml
```

窗口操作速查：

| 操作 | 效果 |
|---|---|
| 空格 | 暂停 / 继续仿真 |
| 右键拖动 | 旋转视角 |
| 滚轮 | 缩放 |
| CTRL + 左键拖动 | 平移视角 |
| 双击物体 | 选中它（信息显示在左侧面板） |
| 选中后 CTRL+拖动 | 施加扰动外力/位姿（做控制实验很有用！） |
| F3 | 切换"物理/几何"渲染显示 |
| F11 | 循环切换渲染选项（网格、坐标轴等） |

Simulate 是**调试工具**，不是你的实验主体。你的实验主体是 Python 脚本（第 3 章起的循环模式），Simulate 用来"肉眼确认模型对不对"。

## 1.6 常见问题速查（本机 Windows 实测）

| 问题 | 处理 |
|---|---|
| `ModuleNotFoundError: mujoco` | 环境没激活或没装：`pip install mujoco` |
| 导入 mujoco 后窗口打不开 | Simulate 是 GUI 程序，需在桌面会话运行（不能纯 SSH 无头） |
| 控制台中文乱码 | Windows 控制台默认 GBK，脚本开头加 `sys.stdout.reconfigure(encoding="utf-8")` |
| `python -m mujoco.simulate` 报错 | 3.11 已移除该模块，改用 `python -m mujoco.viewer` |
| Mac 上 viewer 闪退 | 需要 `mjpython` 启动器（Windows/Linux 不需要，跳过） |
