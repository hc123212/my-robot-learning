## 8.1 传感器的两种来源

MuJoCo 的"测量"有两条路：

1. **直接读状态**：`data.qpos`、`data.qvel`、`data.body().xpos` 等——这些是**真值**，物理引擎内部直接算出来的。
2. **传感器（sensor）**：在 XML 里声明 `<sensor>`，引擎把各种量**打包**进 `data.sensordata`——模拟真实机器人上"传感器测到的值"。

两者数值相同（都来自引擎内部），但组织方式不同。**学习计划里大部分对比实验用第 1 种就够了**；传感器主要用于：RL 观测组织、模拟传感器噪声、批量读取。

## 8.2 定义传感器

```xml
<sensor>
  <jointpos name="jpos" joint="pivot"/>           <!-- 关节角 -->
  <jointvel name="jvel" joint="pivot"/>           <!-- 关节角速度 -->
  <framepos name="tip_pos" objtype="site" objname="tip"/>  <!-- site 位置 -->
  <framequat name="tip_quat" objtype="site" objname="tip"/> <!-- site 姿态四元数 -->
  <framelinvel name="tip_vel" objtype="site" objname="tip"/> <!-- 线速度 -->
  <actuatorforce name="tau_sense" actuator="tau"/> <!-- 执行器力（模拟力传感器）-->
  <gyro name="gyro" site="tip"/>                  <!-- 角速度计 -->
  <accelerometer name="acc" site="tip"/>          <!-- 加速度计 -->
</sensor>
```

常用传感器类型速查：

| 类型 | 输出 | 阶段用途 |
|---|---|---|
| `jointpos` / `jointvel` | 关节角 / 角速度 | RL 观测（阶段 8） |
| `framepos` / `framequat` | site 的位姿 | 末端反馈 |
| `framelinvel` / `frameangvel` | site 的速度 | 阶段 4 速度对比 |
| `actuatorforce` | 执行器输出的力/力矩 | 阶段 6 力控反馈 |
| `touch` | 接触法向力（挂在 site 上） | 抓取（进阶） |
| `gyro` / `accelerometer` | 惯性测量 | 人形平衡（进阶） |

## 8.3 读取 sensordata：布局与索引

所有传感器读数按声明顺序**拼接**在 `data.sensordata`（一个长向量）里。每个传感器有自己的起始位置和维度（存在 model 里）：

```python
mujoco.mj_forward(model, data)   # 传感器在 forward/step 中更新

# 方式 1：按起始位置 + 维度手动切（理解布局）
# 注意（3.11 实测）：adr/dim 是 0 维数组，切片前必须 .item() 转成标量！
start = model.sensor("jpos").adr.item()   # 起始下标
dim = model.sensor("jpos").dim.item()     # 维度（jointpos 是 1）
value = data.sensordata[start:start+dim]

# 方式 2：命名访问器（3.x 推荐，直接可用，无需处理数组标量）
data.sensor("jpos").data                # 该传感器读数（视图）

# 打印全部传感器：每个的名字 + 读数
for i in range(model.nsensor):
    name = mujoco.mj_id2name(model, mujoco.mjtObj.mjOBJ_SENSOR, i)
    s = model.sensor(i)
    print(name, data.sensordata[s.adr.item():s.adr.item()+s.dim.item()])
```

**实测验证过的布局**（第 3 章测试模型）：声明顺序 `[jpos, jvel, tip_pos(3), tau_sense(1)]` → sensordata 长度 6，切片分别为 0:1、1:2、2:5、5:6。

## 8.4 接触信息完整读法（阶段 6 站立分析）

第 6 章 6.6 给过基础读法，这里补充阶段 6 需要的完整用法：

```python
mujoco.mj_forward(model, data)

total_force = np.zeros(3)
for i in range(data.ncon):
    c = data.contact[i]
    force = np.zeros(6)
    mujoco.mj_contactForce(model, data, i, force)   # [Fx Fy Fz  Tx Ty Tz]（世界系）
    total_force += force[:3]
    print(f"接触{i}: geom{c.geom1}×geom{c.geom2} 位置{c.pos.round(3)} "
          f"法向力{force[2]:.1f}N")

print(f"总支持力 = {total_force[2]:.1f}N (机器人总重应≈{model.opt.gravity[2]*mujoco.mj_getTotalmass(model):.1f}N)")
```

**阶段 6 站立判定**：总支持力 ≈ 重力时"基本站稳"。注意：

- 接触力含弹簧阻尼瞬态（落地瞬间会明显大于 mg，稳定后回落）——判定站稳要取稳态窗口的平均。
- 想算 CoP（压力中心）：用 `data.contact[i].pos`（接触点位置）对法向力加权平均。
- `model.geom(c.geom1).name` 可把接触对映射到几何体名字（判断"左脚/右脚/地面"）。

## 8.5 数据采集标准模板（所有阶段通用）

```python
"""采集 → 保存 → 重载 的标准流程（实测模板）。"""
import numpy as np

records = []   # 每步一个 dict，字段名即含义

while data.time < T:
    data.ctrl[:] = controller(model, data)
    mujoco.mj_step(model, data)
    records.append({
        "t": data.time,
        "q": data.qpos.copy(),                    # .copy() 必须！
        "qd": data.qvel.copy(),
        "tip": data.site("tip").xpos.copy(),
        "tau": data.qfrc_actuator.copy(),
    })

# 存盘：npz 或 csv
arr = {k: np.array([r[k] for r in records]) for k in records[0]}
np.savez("exp1.npz", **arr)

# 下次实验直接读回来分析/画图
d = np.load("exp1.npz")
print(d["q"].shape)          # (步数, nq)
```

**三个坑**（前两个会导致数据对不上，务必注意）：

1. `.copy()`：不 copy 会存成最后一帧的重复（第 3 章 3.7 讲过）。
2. **步长不一致**：`data.time` 是累计仿真时间，`records` 的索引步数 ≠ 秒数。画图用 `t` 做横轴，不要用步数。
3. 控制与记录顺序：先 ctrl → 再 step → 再记录，这个顺序下记录的是"这一步之后"的状态。保持全脚本一致，别中途换。

## 8.6 数据可视化建议

```python
import matplotlib.pyplot as plt

# 多曲线 + 真值对照（阶段 2~5 的标配画法）
plt.plot(t, q_true, label="MuJoCo")
plt.plot(t, q_mine, "r--", label="my FK")
plt.plot(t, np.abs(q_true - q_mine), label="error")
plt.legend(); plt.show()
```

画误差曲线（而非只看两条线重合）是"理论公式→仿真数据对照"的最快判读方式。误差量级参考：FK 对比应到 1e-6 级（浮点），数值雅可比 1e-5 级（差分步长限制），动力学对比视积分器 1e-3 级。
