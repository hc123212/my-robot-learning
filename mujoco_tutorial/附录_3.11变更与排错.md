## A.1 3.11 相对旧版（3.x 早期）的破坏性变更

| # | 变更 | 旧写法（网上常见） | 3.11 正确写法 | 影响阶段 |
|---|---|---|---|---|
| 1 | `mj_fullM` 签名 | `mj_fullM(m, dst, d.M)` | `mj_fullM(m, d, dst)` | 5 |
| 2 | `mjData.qM` 移除 | `d.qM` | 只有稀疏 `d.M`；用 `mj_makeM` + `mj_fullM` 展成稠密 | 5 |
| 3 | `mujoco.simulate` 模块移除 | `python -m mujoco.simulate` | `python -m mujoco.viewer --mjcf=xx.xml` | 1 |
| 4 | position 执行器阻尼参数 | `kd="5"`（旧文档） | `damping="5"`（`kd` 会 Schema 报错） | 6、7 |
| 5 | keyframe 的 name 属性 | `<keyframe name="...">` | `<keyframe><key name="..." qpos="..."/></keyframe>` | 3 |
| 6 | 默认 `sleep_tolerance` | 1e-4 | 1e-3（一般无感） | — |
| 7 | 稀疏惯量矩阵 | — | `d.M` 为 CSR 稀疏格式；`mj_fullM` 输出稠密 | 5 |
| 8 | `sensor.adr` / `sensor.dim` 类型 | 旧版标量 | 0 维 numpy 数组，切片前 `.item()` | 8 |

**验证方法**：拿不准就 `python -c "import mujoco; print(mujoco.__version__)"`，≥3.5 就按语义化版本看待 API（每月一版，用前查 changelog：<https://github.com/google-deepmind/mujoco/releases>）。

## A.2 常见错误对照表（按报错信息速查）

### 导入 / 环境

| 报错 | 原因 | 处理 |
|---|---|---|
| `ModuleNotFoundError: No module named 'mujoco'` | 环境没激活/没装 | `pip install mujoco` |
| `ModuleNotFoundError: No module named 'imageio'` | gymnasium MuJoCo 环境缺渲染依赖 | `pip install imageio imageio-ffmpeg`（第 9 章） |
| 中文打印乱码 | Windows 控制台 GBK | 脚本开头 `sys.stdout.reconfigure(encoding="utf-8")` |

### XML 建模

| 报错 | 原因 | 处理 |
|---|---|---|
| `Schema violation: unrecognized attribute: 'kd'` | position 执行器用旧参数名 | 改用 `damping`（A.1 #4） |
| `Schema violation: unrecognized attribute: 'name'`（keyframe 行） | name 写在 `<keyframe>` 上 | 写在 `<key>` 子元素（A.1 #5） |
| `model has no bodies with this name` | 名字拼错/没命名 | 检查 XML 的 name 唯一性 |
| 仿真里关节乱转不停 | hinge 没限位 | `limited="true" range="..."` |
| 相邻连杆互相穿插抖动 | 相邻 geom 碰撞 | 不相邻的 geom 设 `contype="0"` |
| 角度对不上（差 57 倍） | 缺 `<compiler angle="radian"/>` | 加编译器选项 |

### Python API

| 报错 | 原因 | 处理 |
|---|---|---|
| `mj_fullM(): incompatible function arguments` | 用了旧签名 | `mj_fullM(m, d, dst)`（A.1 #1） |
| `qfrc_target should be of size nv` | `mj_applyFT` 第 7 参数字节数错 | 传 `np.zeros(model.nv)`（第 5 章） |
| 记录的数据全是最后一帧 | 没 `.copy()` | 记录时 `.copy()`（第 3 章） |
| 改 qpos 后读 xpos 是旧值 | 没 `mj_forward` 同步 | 三步模式：设 qpos → forward → 读（第 3 章） |
| `data.qpos = ...` 报错 | 整体替换了视图 | 用 `data.qpos[:] = ...`（第 3 章） |
| 质量矩阵全 0 | 没 makeM/step 就读 M | 先 `mj_makeM` 或 `mj_step`（第 6 章） |
| 接触力一直为 0 | 没有 ground/接触几何 | 检查模型有没有 plane geom；球离地多远 |

### viewer / 渲染

| 现象 | 原因 | 处理 |
|---|---|---|
| 窗口冻结 | passive 模式忘 `sync()` | 每步 `viewer.sync()`（第 4 章） |
| 脚本不退出 | `launch` 阻塞在主线程 | 用 `launch_passive` + `with`（第 4 章） |
| 渲染黑屏 | 没 `update_scene` | 先 update 再 render |
| `python -m mujoco.simulate` 报错 | 模块已移除 | `python -m mujoco.viewer`（A.1 #3） |

## A.3 API 速查表（按功能）

### 模型加载与对象

```python
mujoco.MjModel.from_xml_path(path)     # 文件加载
mujoco.MjModel.from_xml_string(xml)    # 字符串加载
mujoco.MjModel.from_zip(zip_reader)    # zip 加载
mujoco.MjData(model)                   # 创建状态
mujoco.mj_name2id(m, mujoco.mjtObj.mjOBJ_JOINT, "name")  # 名→id
mujoco.mj_id2name(m, mujoco.mjtObj.mjOBJ_BODY, id)       # id→名
```

### 仿真步进

| 函数 | 作用 |
|---|---|
| `mj_step(m, d)` | 完整一步（动力学+积分） |
| `mj_step1(m, d)` / `mj_step2(m, d)` | 拆开的半步（调试） |
| `mj_forward(m, d)` | 只算不积分（改状态后同步派生量） |
| `mj_inverse(m, d)` | 逆动力学（输出到 `d.qfrc_inverse`） |
| `mj_resetData(m, d)` | 复位默认位形 |
| `mj_resetDataKeyframe(m, d, id)` | 复位到关键帧 |

### 数据读取（data 上，全部要 .copy() 再存档）

```python
d.qpos / d.qvel / d.qacc / d.ctrl / d.time
d.xpos / d.xquat / d.xmat          # 刚体（世界系）
d.qfrc_inverse / d.qfrc_actuator / d.qfrc_bias / d.qfrc_applied
d.sensordata                       # 传感器拼接
d.ncon / d.contact / d.efc_force   # 接触
d.M                                # 稀疏质量矩阵（CSR，step/makeM 后有效）
```

### 命名访问（model 静态 / data 动态）

```python
m.joint("j") / m.body("b") / m.geom("g") / m.site("s") / m.actuator("a")
m.sensor("s").id / m.keyframe("k").id / m.camera("c").id
d.joint("j").qpos / d.body("b").xpos / d.site("s").xpos / d.actuator("a").ctrl
d.sensor("s").data
# 注意：m.sensor("s").adr / .dim 是 0 维数组，切片前用 .item() 转标量（第 8 章）
```

### 运动学 / 动力学 / 力

```python
mujoco.mj_jacSite(m, d, Jp, Jr, site_id)      # Jp(3,nv) 平移 + Jr(3,nv) 旋转
mujoco.mj_objectVelocity(m, d, mujoco.mjtObj.mjOBJ_SITE, id, vel6, 0)
mujoco.mj_applyFT(m, d, F, T, point, body_id, qfrc_target)   # 外力→等效广义力
mujoco.mj_makeM(m, d)                          # 构建稀疏质量矩阵
mujoco.mj_fullM(m, d, M_dense)                 # 3.11 新签名
mujoco.mj_contactForce(m, d, contact_id, result6)
mujoco.mj_comPos(m, d) / mujoco.mj_rne(m, d)   # 质心 / 牛顿-欧拉
```

### 枚举速查

```python
mujoco.mjtObj.mjOBJ_SITE / mjOBJ_BODY / mjOBJ_GEOM / mjOBJ_JOINT / mjOBJ_SENSOR / mjOBJ_CAMERA
mujoco.mjtCamera.mjCAMERA_FREE / mjCAMERA_FIXED
mujoco.mjtVisFlag.mjVIS_CONTACTPOINT           # 渲染选项
mujoco.mjtIntegrator.mjINT_EULER / mjINT_RK4 / mjINT_IMPLICIT / mjINT_IMPLICITFAST
```
